倉庫かんばん　取扱説明書

よくある質問（Q&A）

カメラが映らない／黒いまま

「カメラ開き直す」を押します。初めての時に出る「カメラの使用を許可」は許可を押してください。それでもだめなら「写真で読む」（写真を撮ると読み取ります）か、Bluetoothのスキャナーで読みます。カメラはインターネットの安全な住所（https）で開いたときだけ使えます。詳しく →

ピッと鳴らない／読めない

「📷 読む」を押してから、QRを枠の中に入れ、20〜30cmくらい離します。暗いときは明るい場所へ。同じQRは、一度枠から外すまで読み直しません（二重登録を防ぐため）。詳しく →

成形後の積付はどうする？

「積付」→ かんばんを読む →「パレット」か「台車」→ 箱数を確かめて「決定」。半端な箱数もここで直せます。詳しく →

QRを何度も読んでしまう／読むタイミング

カメラの下の「📷 読む」を押すと、押してから6秒の間に枠に入ったQR（バーコード）を1つだけ読んで止まります（カメラの映像を押しても同じ）。読めないと「もう一度」と出ます。連続で読み続けたいときは 設定 →「表示・読み取り」→「QRを自動で読み続ける」をオン。

現品表のバーコードで読みたい

現品表のバーコードを読むと品番が分かります。積付では空いているかんばん番号を自動で付けます。入庫では運ぶ途中のパレットから、回収では倉庫にあるパレット（置き場所つき）から選びます。初めてのバーコードは「どの品番か」を1回選ぶと、次から自動で分かります（設定 → 品番マスタ →「現品表のバーコード」）。マスタにない品番なら、出てくる画面の「このコードのまま品番として登録」で箱入数・箱数を入れて登録できます（Excelから取り込み直しても残ります）。

未セット品・セット品・単品を分けたい

積付と入庫の画面に「未セット品」「セット品」「単品」のボタンがあります。押したものに色が付き（未セット＝赤・セット＝緑・単品＝青）、そのパレットに記録されます。品番ごとに前回の選び方を覚えます。あとでセットしたら：入庫 → かんばんを読む →「セット品」を押す（置き場所は今の場所が自動で入ります）→「入庫する」。在庫一覧には区分ごとの枚数、置き場所には区分が出ます。Excelに渡す記録のメモにも区分と「状態変更 未セット品→セット品」が入ります。

倉庫がいくつもある／区画を足したい

読み取り画面の置き場所の地図は、倉庫ごとに1枚ずつです。左右にスライドするか ◀ ▶ で倉庫を切り替えます。「区画を編集」を押すと点線の「＋」が出るので、押して名前を入れると区画が増えます（右端・下端の「＋」で列や行も広がります）。区画を押すと名前の変更・削除（パレットがある区画は変えられません）。「＋倉庫を追加」で倉庫を増やせます。区画の名前は倉庫をまたいで同じにできないので、第2倉庫は「2A-1」のように頭を変えます。

パレットから箱だけ取り出したい（移動）

「移動」→ パレットのかんばん（または現品表）を読む → 取り出す箱数 → 行き先を選ぶ →「移動する」。行き先は2つ：別の区画へ（地図をタップか区画のQR。在庫のまま「バラ◯箱」として残ります）／出荷・持ち出し（在庫から減ります）。パレットの残り箱数は自動で減り、0になると「かんばんを回収しますか？」と出ます。バラ箱を使ったら、在庫タブの「◯◯ バラ◯箱」を押して「持ち出す」。パレットごと別の区画へ動かすときは今までどおり「入庫」です。箱単位の移動はExcelの入出庫記録には入りません（Excelはパレット枚数で数えるため）。「すべての記録をCSV」には入ります。

成形中で何枚になるか分からない

パレットができるたびに「積付」→ かんばん →「決定（成形中・続く）」。読んだ順に「1枚目・2枚目…」と「成形中の品番」に並びます。最後のパレットは「決定して成形終了」、または一覧の「成形終了にする」。在庫タブにも「成形中」と出ます。

入庫と回収はどうする？

入庫：かんばんを読む → 地図で置いた区画をタップ（またはレイアウト図のQR）→「入庫する」。回収：パレットが空になったら「回収」→ かんばんを読む → かんばんは回収箱へ。詳しく →

パレットを別の場所に動かしたときは？

入庫と同じです。かんばんを読むと「今○○にあります」と出るので、新しい区画をタップして「入庫する」。「置き場所を移動」と出ます。詳しく →

本物のかんばんなしで練習したい

「？」→「バーチャル練習」。画面の「仮のQR」を押すと読んだことになり、お題のとおりに進めます。本番の記録には入りません。詳しく →

地図（レイアウト）はどう作る？

Excelのマス目に倉庫の形どおり区画名を書き、その範囲をコピーして、設定 →「区画」に貼り付けます。空のマスは通路になります。入口に貼るQR付きのレイアウト図は、パソコンの「かんばん発行」で作れます。詳しく →

赤い文字が出た

理由が書いてあります。その場で読み直してください。主な理由の一覧はこちら →

ベトナム語・インドネシア語で表示したい

右上の「文/A」ボタンを押すたびに、日本語だけ → ＋ベトナム語 → ＋インドネシア語 → ＋両方 と切り替わります。ボタンと見出しの下に小さく訳が出ます。

画面の上の色が違う

上の帯の色が、いまの作業です。茶色＝積付、紺＝入庫、赤＝回収。「回収」は1回ごと、または1分たつと入庫に戻ります。

間違えて登録した

「1つ前の登録を取り消す」で最後の1件を消せます。もっと前のものは、Excel側の入出庫記録で直します。詳しく →

在庫が0なのに倉庫に物がある

始める前から置いてあるパレットは、最初に全部「入庫」で読んでおく必要があります（最初の棚卸し）。詳しく →

「何日分」「作る数」はどう計算している？

何日分＝倉庫の枚数×パレット1枚の個数÷1日の需要。作る数＝（かんばんの総枚数−倉庫の枚数）×パレット1枚の個数。数字は品番マスタのものを使います。詳しく →

「枚数未設定」と出る

その品番の「パレット1枚に載る箱の数」がまだ入っていません。設定 →「箱数」で入れてください。詳しく →

箱の大きさで、パレットに載る数が違う

設定 →「箱数」で、品番ごとに1枚に載る箱の数を入れます。1枚の個数・発注点・かんばんの総枚数が自動で計算し直されます。詳しく →

Excelにはどう渡す？

記録タブ →「コピー」→ Excel「倉庫在庫かんばん_運用版」の入出庫記録で、最後の行の次のA列を選んで貼り付け →「渡し済みにする」。詳しく →

入れたデータを書き出したい

①Excelの入出庫記録へ：記録タブ「コピー」（またはCSVで保存）→ 貼る →「渡し済みにする」。②全部の記録（積付・成形終了も）：記録タブ「すべての記録をCSV」。③成形の実績：「成形の実績をCSV」。④今の在庫：在庫タブ「在庫一覧をCSVで保存」。⑤丸ごと保存：設定「バックアップ」（戻す用）。

コピーがうまくいかない

「CSVで保存」でファイルにして、Excelで開いてから貼り付けてください。

SDカードで書き出し・取り込みしたい

最初に1回だけ：Chromeの「︙」→「設定」→「ダウンロード」→「ダウンロード先」を「SDカード」にします。書き出し：設定 → SDカード →「まとめて書き出す」で、バックアップ・Excel用の入出庫記録・在庫一覧の3つがSDカードの Download フォルダに入ります（毎日夕方）。取り込み：「ファイルを取り込む」→ 左上「≡」→「SDカード」→ ファイルを選ぶ。バックアップ（.json）なら全部を戻し、品番マスタ（.txt・.csv）なら品番マスタに入ります。SDカードをPCに差せば、そのままExcelで開けます。

品番マスタはどうやって入れる？

いちばん簡単なのはファイルで渡す方法です。①PCの「かんばん発行」→「⑤ 保存・タブレットへ」→「ファイルで保存」（タブレット用_品番マスタ.txt）。またはExcelの品番マスタを「名前を付けて保存 → CSV」。②そのファイルをGoogleドライブ・メール・USBなどでタブレットへ。③タブレットの 設定 → 品番マスタ →「ファイルから読み込む」でファイルを選び、確認で「はい」。Excelの文字コード（Shift_JIS／UTF-8）はどちらでも読めます。

品番マスタを入れ直したい（品番が増えた）

Excelの品番マスタA〜L列をもう一度コピーして「取り込む」。記録は消えません。詳しく →

タブレットが壊れた／買い替えた

毎日「バックアップ → ファイルに書き出す」をしておけば、新しいタブレットで「読み込む」で戻せます。詳しく →

タブレットを2台で使える？

記録はそれぞれのタブレットの中に残ります。2台で使うときは、両方の記録をExcelに貼れば在庫はExcelで正しく出ます。ただし、タブレットの在庫画面はそのタブレットで読んだ分だけです。最初は1台で始めるのがおすすめです。

0. まずテスト運用（この順番で）

3〜5品番・タブレット1台で2〜3週間試し、合格したら品番を増やします。上の帯の色が「いまの作業」です（茶色＝積付、紺＝入庫、赤＝回収）。

手順1　事前の準備（パソコン・生産計画）

  1. テストする品番を3〜5つ決める（出入りが多い・箱の大きさが違う・同じ機械）
  2. 「かんばん発行」①で品番・箱入数・パレットと台車の箱数・発行枚数・発注点を入れる
  3. ②でかんばんを印刷、④で倉庫のレイアウト図（A3）を印刷して入口に貼る。床に区画名を書く
  4. ⑤「タブレット用にコピー」

手順2　タブレットの準備

  1. アプリを開き、カメラを「許可」、ホーム画面に追加
  2. 設定 →「記入者」に名前（入れないと登録できない）
  3. 設定 →「品番マスタ」に貼って取り込む。「区画」にレイアウトを貼って取り込む
  4. 設定 →「箱数」で、パレットと台車の箱数を確かめる

手順3　バーチャル練習（全員・約5分）

  1. 右上の「？」→「バーチャル練習」（または 設定 →「バーチャル練習」→「練習を始める」）
  2. 上に出る「練習のお題」のとおりに、赤く光るボタンや「仮のQR」を押す。本物のかんばんは要りません
  3. お題は6つ：積付 → 入庫 → 場所を移す → 回収 → 間違いの体験 → 在庫を見る
  4. 終わったら上の「練習を終わる」。本番のデータはそのまま残っています（練習の記録とは別）

手順4　本番スタート（最初の棚卸し）

今倉庫にあるテスト品番のパレット全部にかんばんを付けて「入庫」。在庫タブの枚数が実物と合うか確かめる。

手順5　毎日の流れ

  1. 成形後：「積付」→ かんばん → パレット／台車・箱数 →「決定」
  2. 倉庫：「入庫」→ かんばん → 地図をタップ →「入庫する」
  3. 空になったら：「回収」→ かんばん → 回収箱へ
  4. 朝：班長が「指示」を見る（テスト中は見るだけ）
  5. 夕方：事務員がExcelへ渡す →「渡し済み」→ バックアップ

手順6　毎日夕方の確かめ

  • 読む画面の下の一行に赤がない
  • タブレットの枚数と実物が合う
  • 回収箱のかんばんの枚数と、その日の回収の記録が合う
  • 合わなければ日付・品番・差・原因をメモ

手順7　判定（2〜3週後）

見ること合格の目安
実物との差0〜1枚の日8割以上
夕方に「運ぶ途中」0枚の日9割以上
赤が出た理由全部説明できる

1. はじめに（準備）

  1. 右上の「？」→「準備」のガイドを開くと、順番に案内します。
  2. 記入者：名前を入れて「決める」。
  3. 品番マスタ：Excel「倉庫在庫かんばん_運用版」の品番マスタで、4行目から最後の行まで、A〜L列を選んでコピー → ここに貼り付け →「取り込む」。
  4. 区画（レイアウト）：Excelのマス目に倉庫の形どおり区画名を書いてコピー → 設定 →「区画」に貼り付け →「取り込む」。空のマスは通路です。読むタブに倉庫の地図が出ます。
  5. 最初の棚卸し：今倉庫にあるパレット全部に、かんばんを付けて「入庫」で読みます。これをしないと在庫が0のままです。
練習は「練習用のデータを入れる」で。本番の前に、品番マスタを取り込み直せば練習データは消えます（記録は「設定 → SDカード」で残す／消すを決めてください）。

1-2. パレット1枚に載る箱の数

箱の大きさで、パレットに載る数は品番ごとに違います。設定 →「箱数」で品番ごとに入れます。

  1. 機械や品番で絞り込み、「未設定だけ」にチェックすると、まだ入れていない品番だけが出ます。
  2. 「箱数」の欄に、パレット1枚に載る箱の数を入れます。
  3. 1枚の個数（箱入数×箱数）、発注点、かんばんの総枚数がすぐ計算し直されます。
  4. 総枚数が増えたときは、出てくる番号のかんばんを印刷ツールで追加印刷します。減ったときは、出てくる番号のかんばんを回収したら使わずに外します（倉庫にある分は今までどおり回収できます）。
  5. 最後に「Excelへ（品番マスタH列に貼る）」を押し、Excelの品番マスタでH5を選んで貼り付けます。Excelとタブレットの数字がそろいます。
計算の決まり（月の稼働日21日・安全在庫2日・補充日数7日）はExcelと同じです。変えるときは「計算の決まり」を開いて変えます。品番マスタを取り込み直しても、Excelに箱数が入っていない品番は、タブレットで入れた箱数が残ります。

1-3. 成形後の積付（荷姿と箱数）

  1. 成形が終わったら「積付」を押す。
  2. パレット（台車）に付けたかんばんを読む。
  3. 「パレット」か「台車」を選ぶ。いつもの箱数が最初から入っています。
  4. 半端なときだけ「－」「＋」で箱数を直す。入数（個）が出ます。
  5. 「決定」。続けて次のかんばんを読めます。

積付したかんばんは「運ぶ途中」になり、在庫一覧に「途中」と出ます。倉庫で「入庫」すると、積付した個数のまま倉庫の在庫になります。積付をしないで入庫したときは、いつもの箱数（パレット）で数えます。

台車1台の箱数は、設定 →「箱数」の「台車」の欄で品番ごとに決めます。

2. 入庫・回収のしかた

入庫（倉庫に置いた・場所を移した）

アプリはふだんから「入庫」になっています。

  1. パレットのかんばんを読む → ピッ。
  2. 地図で置いた区画をタップ。入口のレイアウト図の区画のQRを読んでも同じ。
  3. かんばんと置き場所を確かめて「入庫する」を押す → 緑で「登録しました」。

地図の数字はその区画のパレット枚数、黄色は同じ品番がある区画、赤い点線はそのかんばんが今ある区画です。

回収（パレットの製品がなくなった）

  1. 「回収」を押す（または操作カード「回収」を読む）。
  2. 外したかんばんを読む → 緑で「回収しました」。かんばんは回収箱へ。

回収は1回ごとに入庫へ戻ります。入庫の画面で倉庫にあるかんばんを読んだときは「このかんばんを回収する」ボタンも出ます。

3. カメラ

  • 読むタブを開くとカメラが動きます。QRを黄色い枠の中に入れてください。
  • 同じQRは、一度枠から外すまで読み直しません（二重登録を防ぐ）。もう一度読みたいときは「やり直す」を押します。
  • カメラはかんばんと、レイアウト図の区画のQRの両方を読みます。
  • 映らないとき：「カメラ開き直す」。初回は「カメラの使用を許可」で許可。
  • どうしても読めないとき：「写真で読む」で写真を撮る、または手で入力してEnter。Bluetoothのバーコードスキャナーも、この入力欄でそのまま使えます。
  • カメラはhttpsの住所（GitHub Pagesなど）で開いたときだけ使えます。ファイルを直接開いたときは「写真で読む」を使ってください。

4. エラーが出たとき（出る文字と直し方の全部）

5. 在庫と生産指示

  • 在庫タブ：品番ごとの枚数と何日分。「どこにある？」で品番を入れると、パレット番号と置き場所が出ます。
  • 指示タブ：在庫が少ない順。欠品（0枚）、生産指示（発注点以下）、もうすぐ（発注点＋1枚）。
  • 作る数＝（総枚数−倉庫の枚数）×パレット1枚の個数。週の割り振りの枠で流すときに、この数だけ作ります。
  • 他の画面の下の黒い帯を押すと、指示タブに移ります。
正式な計画はExcelの「今週の計画」で決めます。タブレットは現場ですぐ見るためのものです。

6. Excelへ渡す（毎日夕方）

  1. 記録タブ →「Excelへ渡す」→「コピー（Excelに貼る）」。
  2. Excel「倉庫在庫かんばん_運用版」の入出庫記録で、最後の行の次のA列を選んで貼り付け。
  3. Excelの「エラー一覧」が0件か確認。
  4. タブレットで「渡し済みにする」。次からは新しい記録だけがコピーされます。

コピーできないときは「CSVで保存」→ Excelで開いて貼り付け。

7. バックアップ

設定 → SDカード →「まとめて書き出す」で、全部の記録と設定を1つのファイルに保存します。新しいタブレットでは「読み込む」で戻せます（今のデータは上書きされます）。毎日夕方、Excelに渡した後に1回。
